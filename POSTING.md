# How to post a story

1. On GitHub, open the `_posts` folder and click **Add file → Create new file**.
2. Name it `YYYY-MM-DD-short-title.md`, using the day you publish
   (example: `2026-11-08-cal-volleyball-sweeps-stanford.md`).
3. Paste this at the top, fill it in, then write the story below the second `---`:

```
---
title: "Cal Sweeps Stanford in Front of a Packed Haas Pavilion"
subtitle: "Optional one-line deck under the headline"
sport: Volleyball            # used for the filter buttons: Football, Volleyball, Basketball, Campus...
event_date: 2026-11-07       # the day the game or event happened
location: Haas Pavilion, Berkeley
image: /images/your-photo.jpg   # optional, but recommended: it is the photo that pops up when someone hovers the headline; upload it to /images first
image_caption: "Optional photo caption and credit"
---

Your lede paragraph goes here. The first paragraph is used as the preview on the Stories page.

Keep writing in plain paragraphs. **Bold** and *italics* work, and so do > block quotes for quotes from players.
```

4. Click **Commit changes**. The story appears at oliviadugan.github.io/blog/ in about a minute.
